# INFOZATECH — Data Science Internship Projects

Welcome to my **InfozaTech Data Science Internship** project repository! This repository contains my data science projects focused on data analysis, visualization, and machine learning using Python.

## 📌 Projects Overview

### 🚢 Task 1: Titanic Survival Prediction

**Objective:** Analyze Titanic passenger data and build a machine learning model to predict passenger survival.

**Tools and Technologies:**
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook

**Implementation:**
- Loaded and explored the Titanic dataset.
- Cleaned and preprocessed passenger data.
- Analyzed survival patterns using data visualizations.
- Built a classification model to predict survival.
- Evaluated model performance using classification metrics.

**Notebook:** [View Titanic Survival Prediction](./InfozaTech_Task1_Titanic_Survival_Prediction.ipynb)

### 🌸 Task 3: Iris Flower Classification

**Objective:** Build a machine learning classification model to predict Iris flower species using sepal and petal measurements.

**Tools and Technologies:**
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook

**Implementation:**
- Loaded and explored the Iris dataset.
- Visualized relationships between flower measurements.
- Split the dataset into training and testing sets.
- Trained a K-Nearest Neighbors (KNN) classification model.
- Evaluated performance using accuracy and a confusion matrix.
- Explored flower species predictions.

**Notebook:** [View Iris Flower Classification](./InfozaTech_Task3_Iris_Classification.ipynb)

---

### 📊 Task 4: Sales Prediction Using Advertising Data

**Objective:** Predict sales based on advertising expenditure across TV, radio, and newspaper channels using machine learning.

**Tools and Technologies:**
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook

**Implementation:**
- Loaded and explored the advertising dataset.
- Analyzed correlations between advertising channels and sales.
- Created data visualizations and a correlation heatmap.
- Trained a Linear Regression model.
- Evaluated model performance using regression metrics.
- Compared actual sales with predicted sales.
- Explored advertising feature importance and interactive sales predictions.

**Notebook:** [View Sales Prediction](./InfozaTech_Task4_Sales_Prediction.ipynb)
